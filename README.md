# PreçoArte

Programa para Windows que calcula o preço certo de produtos de artesanato, sublimação e personalizados. Ele soma materiais, embalagem, as contas do mês e o seu tempo, e mostra o preço com o lucro que você escolher. Também monta orçamentos prontos para o WhatsApp.

## Baixar

[**Baixar o PreçoArte para Windows**](https://github.com/Edyfran/PrecoArte/releases/latest)

Na página da versão mais recente, clique em `PrecoArte-Setup-<versão>.exe`.

- Windows 10 ou 11
- 15 dias de teste grátis, com tudo liberado
- Funciona sem internet. Os seus dados ficam no seu computador.

## Aviso do Windows na instalação

O Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece com programas de desenvolvedores independentes.

## Atualizações

O programa instalado procura versões novas sozinho e avisa quando houver uma pronta para instalar. Os seus dados não são alterados.
